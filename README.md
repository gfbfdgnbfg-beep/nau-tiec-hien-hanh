# Website nấu tiệc

## Cách sử dụng
1. Mở thư mục này bằng VS Code.
2. Cho ảnh thật vào thư mục `images`.
3. Đặt đúng tên ảnh:
   - hero.jpg
   - mon-1.jpg ... mon-6.jpg
   - anh-tiec-1.jpg ... anh-tiec-6.jpg
4. Mở `index.html` bằng trình duyệt hoặc dùng Live Server.
5. Thay số điện thoại, địa chỉ, khu vực phục vụ và tên thương hiệu trong `index.html`.

## Gợi ý
Sau khi hoàn thiện, có thể đưa project lên GitHub và xuất bản bằng GitHub Pages hoặc Vercel.
